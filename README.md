<summary><b>LSTM 기반 뇌파(EEG) to 해마 BOLD 신호 추정 및 예측 가능성 통계 검증</b></summary>

[기간] 2024.06 ~ 2024.08

[역할] 모델 설계, 하이퍼파라미터 탐색, 통계 검정 및 해석

[상황 및 과제]
고비용·고해상도 정밀 계측 장비의 시간·비용적 한계를 극복하기 위해, 저비용·고속 수집이 가능한 75명 26채널 뇌파(EEG) 시계열 데이터로 해마 BOLD 신호를 추정하는 LSTM 예측 모델 구축

[핵심 수행]
- 입력 데이터 구성: 26채널을 4개 주파수 대역으로 나눠 104개 입력 특징 구성, 뇌파와 BOLD 반응 사이 지연을 5스텝으로 정렬해 실험 구간당 42시점 시퀀스로 재구성. 모든 구간에 공통 반복되는 파형은 학습 분할에서만 계산해 제거하고, 남은 차이값을 예측 대상으로 설정
- LSTM 구조 설계: 입력층(104) → LSTM 은닉층(시퀀스 출력) → 드롭아웃 → 완전연결층(1) → 회귀층. 활성화 함수 없는 완전연결층 2개는 하나의 선형 변환으로 붕괴하므로 단층 배치
- 학습 조건 설정: Adam, 최대 120 epoch, 배치 크기 64, 전체 구간의 1/3마다 학습률 0.3배 감쇠, 검증 손실 10회 미개선 시 조기 종료 후 최저 손실 시점 가중치 채택
- 베이지안 최적화: 은닉 유닛 수·드롭아웃·학습률·L2 규제를 50회 탐색 (은닉 유닛 21, 드롭아웃 0.564, 학습률 8.17e-3, L2 2.15e-6). 후보 비교는 3-fold 교차 검증으로 수행하고 테스트 데이터는 탐색에 사용하지 않아 선택 편향 차단
- 결과 검증: 피험자와 실험 구간을 함께 분리해 정답 유출 방지, 선형회귀·무예측·시간 순서 셔플 재학습을 비교 기준으로 순열검정과 피험자 단위 검정 수행
